# Calix 3D Custom Emoji Suite

Public asset repository for Calix's 3D custom emojis and visual reaction stickers.

## Directory Structure
- `emojis/crisp_inline/` - High-DPI 48x48 Retina icons (recommended for 24px inline markdown display)
- `emojis/tiny_24/` - Ultra-compact 24x24 micro-icons
- `emojis/inline_32/` - 32x32 standard icons
- `emojis/cutouts/` - 256x256 high-resolution transparent PNG stickers

## Usage in Markdown (Crystal Clear)
```html
<img src="https://raw.githubusercontent.com/maniyajay7/calix_emogi/main/emojis/crisp_inline/04_calix_3d_queen_hair_crisp.png" width="24" height="24" style="vertical-align:middle;display:inline-block;" alt="Calix Queen" />
```
